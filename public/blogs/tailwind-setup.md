# Tailwind CSS Setup Guide

Get Tailwind running in minutes with sensible defaults and production-ready configuration.

## Install

Install Tailwind, PostCSS, and Autoprefixer. Initialize the config files.

## Configure

Update `tailwind.config.js` to scan `src/**/*.{ts,tsx}`. Enable the typography plugin for rich content.

## Styles

Import the base, components, and utilities directives into your `index.css`. Start composing utility classes and keep components small.
